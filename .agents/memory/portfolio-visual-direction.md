---
name: Portfolio visual direction
description: The user's lasting tone and photo-palette direction for both portfolio implementations.
---

Keep the portfolio whimsical and warm, with a cottage-core sensibility. Around portrait images, keep the leafy ornaments orange and blue and use green as a soft background gradient, not as the leaf color.

**Why:** The user chose warm, whimsical typography and an autumn-photo palette, then explicitly clarified that the leaf ornaments should remain orange and blue while the green appears in the gradients.

**How to apply:** Carry this visual direction through design changes to both the Jekyll GitHub Pages site and the React Replit companion.
