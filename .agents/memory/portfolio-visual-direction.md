---
name: Portfolio visual direction
description: The user's lasting tone and photo-palette direction for both portfolio implementations.
---

Keep the portfolio whimsical and warm, with a cottage-core sensibility. Use colors from portrait photos the user supplies for the portfolio when extending its palette.

**Why:** The user explicitly said whimsy is the goal, chose whimsical and warm cottage-core typography, and asked that supplied portrait-photo colors shape the design.

**How to apply:** Carry this visual direction through design changes to both the Jekyll GitHub Pages site and the React Replit companion.
